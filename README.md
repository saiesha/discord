# Discord / Scheduled Task Experiment

A small Python experiment exploring scheduled background tasks with the `schedule` library.

## What it does

The current script registers recurring jobs and prints a message when a scheduled job runs.

The repository is intentionally kept small: it is an early experiment rather than a production-ready bot.

## Run locally

```bash
pip install -r requirements.txt
python dis
```

## Example

The current experiment schedules jobs at different intervals:

- Every 10 seconds
- Every 10 minutes
